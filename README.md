# O'Brien Hope Sibande — Data Science Portfolio

Responsive static portfolio website with dark navy and cyan colors, professional portrait, a featured FPL Edge project, capabilities, FPL Edge featured project, contact links, and a project case study.

## Files
- `index.html` — homepage
- `styles.css` — responsive design system
- `script.js` — mobile navigation and current year
- `assets/obrien-hope-sibande.webp` / `.jpg` — optimised portrait (WebP with JPEG fallback)
- `assets/og-image.jpg` — 1200×630 social share image
- `projects/fpl-edge/index.html` — FPL Edge case study
- `sitemap.xml`, `robots.txt` — search engine hints

## Run locally
From this directory, run `python -m http.server 8000`, then open http://localhost:8000.

## Deploy
Import this folder into Vercel as a static project. No build command is required; use `.` as the output directory if prompted.
