# O'Brien Hope Sibande — Data Science Portfolio

Responsive static portfolio website with a dark navy and cyan design, professional portrait, capabilities, selected work and an FPL Edge case study.

## Files
- `index.html` — homepage
- `styles.css` — responsive design system
- `script.js` — mobile navigation, progressive enhancements and current year
- `assets/obrien-hope-sibande.webp` — professional portrait (optimized WebP)
- `assets/og-image.webp` — social sharing image
- `projects/fpl-edge/index.html` — FPL Edge case study
- `vercel.json` — deployment settings

## Run locally
From this directory, run `python -m http.server 8000`, then open http://localhost:8000.

## Deploy
This is a static site; no build command is required. For Vercel, set the output directory to `.` if prompted.
